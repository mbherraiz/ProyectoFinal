# ProyectoFinal

Mi idea consiste en crear un lanzador y organizador de videojuegos personalizado para PC centrado en Steam, diseñado en Python con una interfaz moderna y optimizada. El objetivo principal es ofrecer una biblioteca visual y rápida donde se pueda gestionar e iniciar los juegos de forma instantánea, controlando el cliente oficial de Steam en segundo plano mediante parámetros de inicio ligeros. De esta manera, se logra eliminar el consumo excesivo de recursos del sistema mientras se mantiene la validación de licencias y el acceso a los títulos con el máximo rendimiento posible.

El plan de trabajo tendrá varios pasos:
  1- Desarrollar la idea principal, con todo lo que se usara en el código en python
  2- Pedirle un prompt estructurado a Gemini que implemente todo lo necesario
  3- Pasar el prompt generado anteriormente al agente Antigravity
  4- Verificar el trabajo que realizó el agente
  5- Pedirle cambios y solución de errores
  6- Perfeccionar el programa
  7- Subir una versión al repositorio en GitHub
